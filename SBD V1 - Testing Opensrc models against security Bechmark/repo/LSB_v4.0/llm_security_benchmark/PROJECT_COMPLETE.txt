📊 KEY METRICS IMPLEMENTED
════════════════════════════════════════════════════════════════════════════════

From Pearce et al. (2021) IEEE S&P 2022:

1. VULNERABILITY RATE (V%)
   └─ % of generated code with security issues
   └─ Lower is better (Copilot: ~40%, Claude: ~23%)

2. SECURE-PASS@k
   └─ Probability ≥k samples are secure & functional
   └─ Higher is better (Pass@5 > 0.8 is good)

3. TOP-1 SECURITY RATE (TNV%)
   └─ % of default suggestions that are non-vulnerable
   └─ Higher is better (> 80% is good)

4. SAST FINDING DENSITY
   └─ Security violations per 100 LOC
   └─ Lower is better (< 0.5 is good)

5. FUNCTIONAL CORRECTNESS
   └─ % passed unit tests
   └─ Higher is better (100% is target)
